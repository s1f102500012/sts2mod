# 1.1.4

【修复】

- 修复内部校验解析错误导致破损核心、注能核心、天命所归和无界命匣的部分强化效果未加载的问题；
- 修正破损核心在额外回合下未按个人第3回合获得集中、或在同一全局轮内重复获得集中的问题；
- 修正注能核心在首轮包含额外回合时重复获得集中的问题；

【优化】

- 破损核心沿用游戏的效果结算上下文，并补充两件核心的集中触发与施加结果日志，便于排查兼容问题；

【注意】

- 仍支持游戏 0.107.1 和 0.111.0，以及两个版本的可选观者适配；
- 联机玩家须使用相同模组版本；未改变存档字段和遗物 ID；

# 1.1.3

【优化】

- 支持将 lamali 或 Boninall 的观者模组作为可选前置；
- 至纯之水：在每场战斗开始时，将1张奇迹放入你的手牌，并获得2层真言；
- 圣水：在每场战斗开始时，将3张奇迹放入你的手牌，并获得5层真言；
- 补充中英文强化描述和真言提示，数字使用蓝色，奇迹与真言使用金色；

【注意】

- 两个观者模组任选其一，并满足其自身版本与依赖要求；未安装观者时本模组仍可独立使用；
- 保留原作者的奇迹生成与真言结算逻辑，其它角色遗物效果不变；
