# 已知限制

- 抹杀使用游戏私有成员、Harmony ReversePatch 和异步状态机 Transpiler，因而
  对游戏版本敏感；新游戏版本必须重新做成员、签名和 IL 验证。
- 编译成功只能证明公开 API 兼容，静态 Hook 验证只能证明当前引用程序集的目标
  形状匹配。
- Headless 初始化只能证明 Loader 选择、程序集加载和初始化链路，不证明具体战斗
  行为、死亡动画、存档恢复或联机一致性。
- 未完成双端联机运行测试时，不声称联机行为已经通过实测。
- 精确对象硬收敛会直接维护战斗集合并通知现有监听者。这是原版移除原语未能完成
  后的兜底路径，仍需在每个游戏版本复核事件语义和缓存副作用。
- 专门识别本程序集并取消其补丁、替换运行时或篡改游戏进程的实现，不属于普通
  游戏机制和常规模组互操作保证。
